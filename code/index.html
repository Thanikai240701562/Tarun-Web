Deterministic AI

Classical Heuristic Search & Constraint Satisfaction

Unlike stochastic generative models that hallucinate, TeamForge formulates team generation as a formal Constraint Satisfaction Problem (CSP) solved with 100% mathematical guarantees in pure server-side algorithms.

MRV Variable Ordering Heuristic

Prioritizes assigning variable slots with the Minimum Remaining Values (MRV) first, drastically pruning downstream combinatorial branches.

Constraint Propagation & Forward Checking

Whenever a candidate is provisionally assigned, conflicting domains are immediately pruned. If any variable domain reaches zero, backtracking initiates instantly.

Hill Climbing Local Search

Iteratively evaluates candidate swaps in the 1-opt neighborhood to maximize the multi-objective skill balance and experience distribution score.
